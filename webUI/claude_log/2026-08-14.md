## Session: header links opening in new tabs instead of navigating in place

**bug:** on `index_interpolate.html`, the "❓interpolation" header button
opened `interpolate_blog.html` in a new tab, while the reverse link (blog's
"🧮 Try the calculator" button) navigated in the current tab — inconsistent.

**cause:** the three header buttons on `index_interpolate.html`
("❓interpolation", "🏠Home", "🪄Advanced") all had `target="_blank"
rel="noopener"` and pointed at absolute external URLs
(`https://ryuora144.duckdns.org/...`), unlike the blog page's link back,
which had no `target` and used a root-relative local path.

**fix** (`prj/interpolate/index_interpolate.html`), old lines kept as
HTML comments above each replacement:
- ❓interpolation → `/prj/interpolate/interpolate_blog.html` (no `target`)
- 🏠Home → `/index.html` (no `target`)
- 🪄Advanced → `/prj/interpolate/index_interpolate.html`, self-link — user
  confirmed this since the old URL (`https://ryuora144.duckdns.org/interpolate`)
  already pointed at this same page in production, with no separate
  "advanced" page existing yet

**result:** all three header links now navigate in the current tab, matching
the blog page's link back to the calculator.
