# Topic authoring rules

Loaded when working inside `topics/`. These apply to a single subject's pages.

## spec.json is the single source of truth

Both the article and the calculator read from `spec.json`. Never duplicate a dataset,
a parameter range, or a default value into `blog.md` or `calculator.ts`. If the article
says "with 5 points and a cubic fit," those numbers come from the spec, so the demo
below it cannot drift into showing something different.

Required fields:

```json
{
  "slug": "interpolation",
  "title": "What is interpolation?",
  "description": "<155 chars, written for search results",
  "socialImage": "og.png",
  "category": "signal-processing",
  "difficulty": "intro",
  "prerequisites": [],
  "related": ["smoothing"],
  "levels": ["blog", "calculator"],
  "insight": "One sentence: what the reader should leave knowing.",
  "dataset": { "x": [], "y": [] },
  "parameters": [
    { "name": "method", "type": "enum", "values": ["linear", "cubic"], "default": "linear" }
  ]
}
```

`levels` declares which pages exist. Never assume all three are present — a topic with
no advanced page must generate correct navigation without manual fixes.

## Fixtures

`fixture.json` is generated by a script in `tools/fixtures/`, never written by hand and
never produced by the TypeScript implementation. The point is an independent reference:
if both sides come from the same code, the test proves nothing.

Regenerate with `python tools/fixtures/<slug>.py` when the spec's dataset changes.

## Page metadata

Title, description, and social image come from `spec.json` and are applied by the shell.
Do not write `<meta>`, `<title>`, `<link rel="canonical">`, or analytics tags inside a
topic page.

## SEO targeting

Target the question, not the term. "Interpolation" competes with Wikipedia and MathWorks
and will not rank. "Why does cubic interpolation overshoot" is a real search with thin
competition, and it is the question an interactive demo answers better than static prose.
The `<h1>` should match that question.

## Analytics events

Register the topic's own interaction events — slider touched, method switched, demo
reset, advanced link clicked. Pageviews alone cannot distinguish a four-second bounce
from a six-minute read, and engagement is the only feedback loop the author has.
