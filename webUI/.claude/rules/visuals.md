# Visual grammar

1. Shape carries meaning.
2. Color from chart.js palette (options.colors) or style.css :root tokens. No --c-* tokens exist.
3. Original data — solid dots.
4. Computed result — solid line.
5. Ground truth — dashed line.
6. Discarded — same color, 30% opacity.
7. Active parameter — --accent.
8. Same series keeps one color across layers. Never invent topic colors.
