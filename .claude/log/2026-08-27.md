## Decided
1. **One idea = one file, at 1st too.** Reverses the 08-25 rule.
2. A page holding several ideas becomes a hub plus one child per idea. A page holding one
   idea stays one file with no hub.
3. Split only when a `##` section is useful without the rest. Default is not to split.
4. Hub owns title, tags, url and `%`. A child carries body plus a `<` parent link.
5. Compression on a hub is every child body summed over the one source.
6. Server facts moved out of the public vault `CLAUDE.md` into the private HANDOVER.

## Things that bit, in order
1. **Skills hot-load. The 08-25 log says they do not.** `reform` appeared in the skill list
   immediately after being written, four times, with no `/exit`. The old claim was wrong.
2. **But the injected skill body can be stale.** One `/reform` invocation carried a body
   from before the last two edits. Disk was correct; the injection was not. Reading the
   `SKILL.md` off disk before following it is the cheap guard. A restart also clears it.
3. **`grep -c` ignores `-o`.** It counts matching lines, not occurrences. The first
   absolute-word preservation check reported false differences on reflowed text. Use
   `grep -o ... | wc -l`.
4. **Reform grows files.** Numbering and one-idea-per-item cost characters. Every
   shape-only pass came out over 100%. The vault `CLAUDE.md` hit 110% before the cuts.
   Growth is the honest result, not a failure — say the number.
5. **`reform` step 6 sent cut facts to `HANDOVER.md`.** When the target *is* `HANDOVER.md`
   there is no destination. The hardcoded file name was removed; the rule is now "find
   where else it lives, name that file and line".
6. **A fact can die between two files.** The SB attachment rule (`#884`) was cut from
   HANDOVER as "the vault owns it", and would have been cut from the vault as "operational".
   It existed nowhere else. Restored to HANDOVER *before* the vault section moved.
7. **First cut of My_projects landed at 41%.** Over the ~40% ceiling. Cut again to 38%.
   The threshold only works because it is measured, not estimated.
8. **A trim can make its own file stale.** Adding "uncommitted in git" to HANDOVER's
   Not-done list made that very bullet wrong the moment it was written.
